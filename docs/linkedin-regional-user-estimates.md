## 2. Cited global context

## 3. Methodological limitations

- `Registered users` is not the same as `active users`.
- LinkedIn figures change rapidly and may come from advertising estimators or secondary sources.
- Territorial comparisons should use the same period and definition.
- These figures should not be used to infer personal attributes of specific individuals.
