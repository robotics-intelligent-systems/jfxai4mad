## 2. Contexto laboral citado

El texto original identifica como ejemplos de menor desempleo a República Checa, Polonia y Malta, y como ejemplos de mayor desempleo a Finlandia y España. También sitúa el promedio de la Unión Europea alrededor del 6%.

## 3. Correcciones metodológicas

Para que la comparación sea válida:

1. Usar el mismo período de observación para todos los países.
2. Citar la definición oficial de desempleo y si la cifra está desestacionalizada.
3. Distinguir claramente **miembros registrados** de LinkedIn de **usuarios activos**.
4. No asumir que un mayor desempleo implica mayor disponibilidad para una propuesta concreta.
5. Separar países de la UE de países europeos fuera de la UE cuando se comparen políticas laborales.

## 4. Fuentes recomendadas

- **Eurostat** para desempleo en la Unión Europea.
- Oficinas estadísticas nacionales cuando corresponda.
- Datos oficiales o estimaciones documentadas de LinkedIn para el tamaño de audiencia.
