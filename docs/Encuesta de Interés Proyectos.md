# Encuesta de interés: proyectos multipropósito y modelo de colaboración

Esta encuesta permite identificar intereses técnicos, comerciales y de impacto social, así como el esquema de participación preferido.

## 1. Proyectos de interés

Seleccione una o varias opciones:

- [ ] **Vehículos recreativos y hábitat móvil:** camper, overlanding y habitabilidad autosustentable.
- [ ] **Simuladores de entrenamiento y tecnología inmersiva:** hardware/software para capacitación, conducción o simulación profesional.
- [ ] **Unidades móviles de impacto social, salud o emergencias:** laboratorios, consultorios o centros itinerantes.
- [ ] **Co-working, co-living e infraestructura sostenible:** módulos habitacionales o de trabajo adaptables.
- [ ] **Aulas móviles de tecnología y capacitación:** infraestructura de cómputo para alfabetización digital y talleres.

## 2. Modelo de participación

- [ ] **100% pro bono / voluntariado:** contribución sin retorno económico esperado.
- [ ] **Comercial / comisión por resultados:** participación remunerada según ventas o recursos generados, con condiciones por escrito.
- [ ] **Modelo híbrido:** tareas voluntarias delimitadas más comisión por resultados claramente definida.
- [ ] **Socio fundador / co-inversor:** aporte de capital o equipamiento bajo un acuerdo separado de inversión.

> La condición remunerada, voluntaria o de inversión debe quedar claramente diferenciada antes de iniciar actividades.

## 3. Área de aporte

- [ ] Comercial y ventas.
- [ ] Desarrollo técnico / ingeniería / IT.
- [ ] Gestión administrativa, legal o financiera.
- [ ] Operaciones, logística y atención al cliente.

## 4. Motivación principal

- [ ] Generar ingresos extra mediante un esquema transparente.
- [ ] Obtener experiencia práctica y portafolio.
- [ ] Generar impacto social positivo.
- [ ] Conectar con una red profesional colaborativa.

## 5. Disponibilidad inicial

- [ ] **Ocasional:** pocas horas por semana o tareas puntuales.
- [ ] **Parcial:** aproximadamente 5–10 horas semanales.
- [ ] **Por proyecto:** participación durante un alcance y período definidos.
