## 2. Contexto global citado

El archivo original menciona más de **1.300 millones** de usuarios registrados globales y señala al grupo de **25–34 años** como uno de los segmentos de mayor representación.

## 3. Limitaciones metodológicas

- `Usuarios registrados` no equivale a `usuarios activos`.
- Las cifras de LinkedIn cambian con rapidez y pueden provenir de estimadores publicitarios o fuentes secundarias.
- Las comparaciones territoriales deben usar el mismo período y la misma definición.
- No deben utilizarse estas cifras para inferir atributos personales de individuos concretos.
